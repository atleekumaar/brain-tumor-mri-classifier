Interpretation Protocol & Neural Feature Localization

What is Grad-CAM?

Gradient-weighted Class Activation Mapping computes the gradients of the predicted class score with respect to the final convolutional feature maps (256 filters × 14 × 14 resolution). High activation values denote anatomical regions that most heavily influenced the neural network's classification.

Research Guidance

Verify that peak activation maps correspond to expected intra-cranial anatomical abnormalities (e.g., hyper-intense extra-axial mass for meningioma or sellar region for pituitary). If activation occurs in non-brain background, the prediction may indicate confounding artifact.

Strict Medical Non-Use Policy: Never interpret predictions as clinical diagnosis. Brain tumors encompass complex histological subtypes and immunohistochemical markers that cannot be solely determined from single 2D MR images without tissue biopsy and multimodal clinical workups.

Dataset & Preprocessing Protocol

The neural network was trained on 5,600 verified brain MRI slices across four balanced categories: Glioma, Meningioma, No Tumor, and Pituitary. Testing was performed on a held-out set of 1,600 images achieving 94.56% validation accuracy.

  • Input images are resized to 224×224 pixels with bilinear interpolation.
  • Channels are normalized: Mean [0.485, 0.456, 0.406], Std [0.229, 0.224, 0.225].
  • Feature maps are extracted via four sequential Conv2D + ReLU + MaxPool blocks.

Research Methodology & Interpretability

Grad-CAM (Gradient-weighted Class Activation Mapping) computes the gradients of the target classification score with respect to the final convolutional feature map, generating coarse 2D heatmaps highlighting spatial regions influencing the model's prediction.

  • Heatmap values are normalized between 0.0 (baseline) and 1.0 (peak attention).
  • Red/Warm tones indicate morphological features strongly correlated with the predicted tumor class.
  • Blue/Cool tones indicate lower neural weight contribution.
